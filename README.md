# Who-s-the-imposter-app

Een Nederlandstalige pass-and-play webapp voor het gezelschapsspel "Who's the Imposter". Alle spelers spelen om de beurt op één telefoon: iedereen krijgt hetzelfde geheime woord te zien, behalve de imposter(s). Na een discussieronde stemt de groep op wie zij denken dat de imposter is.

## Ontwikkelen

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
